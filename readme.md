# Sistema Local de Gestión de Facturas

Aplicación multiparadigma en Python para gestionar facturas en PDF usando SQLite.

## Tecnologías
- Python 3
- SQLite3
- Paradigma imperativo
- Orientado a objetos
- Funcional


## Ejecutar pruebas
```Python
pytest -v
```

## Estructura
Ver `/docs`.

# 🧩 Guía de Contribución

## Estilo de código
- PEP8
- Comentarios claros
- Docstrings en clases y funciones

## Reglas para commits
- Ingles o español pero consistentes
- Prefijo:
  - feat: nueva función
  - fix: corrección
  - test: pruebas
  - docs: documentación
  - chore: mantenimiento

## Flujo
1. Crear rama  
2. Hacer cambios  
3. Ejecutar pruebas  
4. Pull Request
